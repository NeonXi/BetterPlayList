### 1.2 分层原则

| 层 | 职责 | 依赖方向 |
|----|------|----------|
| 表现层 | 用户交互、输入校验、结果展示 | 只依赖应用层 |
| 应用层 | 业务流程编排、事务边界、错误处理 | 依赖领域层 + 基础设施层 |
| 领域层 | 核心业务逻辑（随机算法、歌曲模型） | 无外部依赖（纯 Python） |
| 基础设施层 | 外部系统交互（网易云API、协议、存储） | 无，被上层调用 |

**依赖倒置原则**：应用层依赖领域层定义的抽象接口，基础设施层实现这些接口。

## 二、各层详细设计

### 2.1 表现层 (Presentation Layer)

#### 职责
- 接收用户输入（歌单 ID、随机算法选择、是否去重等）
- 调用应用层服务
- 展示执行结果（抓取数量、随机结果预览、插入状态）

#### 模块设计

| 模块 | 类型 | 说明 |
|------|------|------|
| `MainWindow` | 类 | Tkinter 主窗口，含歌单ID输入框、算法下拉框、执行按钮 |
| `ConsoleView` | 类 | CLI 模式视图，argparse 解析参数 |
| `ResultDisplay` | 类 | 结果展示组件（歌曲列表、状态日志） |

#### 输入参数定义
```python
@dataclass
class ShuffleRequest:
    playlist_id: str           # 网易云歌单ID
    strategy: str = "super"    # 随机策略: super / weighted / pure_random
    dedupe_recent: bool = True # 是否启用近期去重
    dedupe_window: int = 20    # 去重窗口大小
```

---

### 2.2 应用层 (Application Layer)

#### 职责
- 编排"抓取 → 随机 → 插入"完整流程
- 管理执行上下文（当前歌单、历史记录）
- 统一错误处理与日志

#### 核心类：`ShuffleAppService`

```python
class ShuffleAppService:
    def __init__(
        self,
        fetcher: PlaylistFetcher,        # 基础设施层接口
        shuffler: ShuffleStrategy,       # 领域层策略
        inserter: QueueInserter,         # 基础设施层接口
        history: HistoryStore,           # 基础设施层
        logger: Logger
    ):
        ...

    def run(self, request: ShuffleRequest) -> ShuffleResult:
        """主流程编排"""
        # 1. 抓取歌单
        playlist = self.fetcher.fetch(request.playlist_id)
        self.logger.info(f"抓取到 {len(playlist.songs)} 首歌")

        # 2. 获取历史记录
        recent_ids = self.history.get_recent(request.dedupe_window) \
            if request.dedupe_recent else []

        # 3. 随机打乱
        shuffled = self.shuffler.shuffle(playlist.songs, recent_ids)

        # 4. 插入播放队列
        self.inserter.insert([s.id for s in shuffled])

        # 5. 记录历史
        self.history.append([s.id for s in shuffled])

        return ShuffleResult(
            playlist_name=playlist.name,
            total=len(shuffled),
            shuffled_songs=shuffled,
            strategy=request.strategy
        )
```

#### 应用层不包含的内容
- ❌ 不直接调用网易云 API（通过 `PlaylistFetcher` 接口）
- ❌ 不实现随机算法（委托给 `ShuffleStrategy`）
- ❌ 不直接调 orpheus 协议（通过 `QueueInserter` 接口）

### 2.3 领域层 (Domain Layer)

#### 职责
- 核心业务模型（歌曲、歌单）
- 随机算法策略（可插拔）
- 不依赖任何外部库

#### 随机算法策略（策略模式）

```python
from abc import ABC, abstractmethod

class ShuffleStrategy(ABC):
    """随机策略接口"""
    @abstractmethod
    def shuffle(self, songs: list[Song], recent_ids: list[str]) -> list[Song]:
        ...


class PureRandomShuffle(ShuffleStrategy):
    """纯随机：Fisher-Yates 公平洗牌"""
    def shuffle(self, songs, recent_ids):
        import random
        arr = songs[:]
        random.shuffle(arr)
        return arr


class SuperShuffle(ShuffleStrategy):
    """强力打乱：公平洗牌 + 近期去重 + 同歌手不相邻"""
    def shuffle(self, songs, recent_ids):
        # 详见可行性计划.md 第四章
        ...


class WeightedShuffle(ShuffleStrategy):
    """热度加权随机（扩展）"""
    def shuffle(self, songs, recent_ids):
        ...


class ShuffleStrategyFactory:
    """策略工厂"""
    @staticmethod
    def create(strategy_name: str) -> ShuffleStrategy:
        strategies = {
            "pure_random": PureRandomShuffle,
            "super": SuperShuffle,
            "weighted": WeightedShuffle,
        }
        return strategies[strategy_name]()
```

#### 2.4.1 歌单抓取：`NcmApiClient implements PlaylistFetcher`

```python
from pyncm import apis

class PlaylistFetcher(ABC):
    @abstractmethod
    def fetch(self, playlist_id: str) -> Playlist:
        ...


class NcmApiClient(PlaylistFetcher):
    """基于 pyncm 的网易云 API 客户端"""

    def __init__(self, cookie: str = None):
        if cookie:
            from pyncm import GetCurrentSession
            GetCurrentSession().headers['Cookie'] = cookie

    def fetch(self, playlist_id: str) -> Playlist:
        # 1. 获取歌单元信息
        detail = apis.playlist.GetPlaylistDetail(playlist_id)
        playlist_info = detail['playlist']

        # 2. 分页获取全部歌曲
        all_songs = self._fetch_all_tracks(playlist_id)

        # 3. 转换为领域模型
        songs = [self._to_song(t) for t in all_songs]

        return Playlist(
            id=playlist_id,
            name=playlist_info['name'],
            cover_url=playlist_info['coverImgUrl'],
            songs=songs
        )

    def _fetch_all_tracks(self, playlist_id: str) -> list:
        """分页抓取（单次最多1000首）"""
        all_tracks = []
        offset = 0
        while True:
            result = apis.playlist.GetPlaylistTracks(
                playlist_id=playlist_id, limit=1000, offset=offset
            )
            tracks = result['songs']
            all_tracks.extend(tracks)
            if len(tracks) < 1000:
                break
            offset += 1000
        return all_tracks

    def _to_song(self, raw: dict) -> Song:
        return Song(
            id=str(raw['id']),
            name=raw['name'],
            artist=raw['ar'][0]['name'],
            album=raw['al']['name'],
            duration_ms=raw['dt'],
            popularity=raw.get('pop', 0)
        )
```

##### 实现①：`OrpheusAddToNextInserter`（orpheus:// addToNext）

```python
import base64, json, subprocess

class OrpheusAddToNextInserter(QueueInserter):
    """通过 orpheus:// 协议逐首添加到下一首"""

    def insert(self, song_ids: list[str]):
        # 逆序插入：addToNext 是插到当前播放的下一首，
        # 逆序才能保持最终顺序正确
        for song_id in reversed(song_ids):
            self._send_orpheus({
                "cmd": "playingList",
                "type": "addToNext",
                "value": song_id
            })

    @staticmethod
    def _send_orpheus(payload: dict):
        json_str = json.dumps(payload, separators=(',', ':'))
        encoded = base64.b64encode(json_str.encode()).decode()
        subprocess.run(
            ["cmd", "/c", "start", "", f"orpheus://{encoded}"],
            shell=True, capture_output=True
        )
```

##### 实现②：`TempPlaylistInserter`（临时歌单方案）

```python
class TempPlaylistInserter(QueueInserter):
    """通过临时歌单 + orpheus:// 播放歌单实现"""

    def __init__(self, temp_playlist_id: str, cookie: str):
        self.temp_pid = temp_playlist_id
        from pyncm import GetCurrentSession
        GetCurrentSession().headers['Cookie'] = cookie

    def insert(self, song_ids: list[str]):
        from pyncm import apis
        # 1. 清空临时歌单
        existing = apis.playlist.GetPlaylistTracks(
            playlist_id=self.temp_pid, limit=1000, offset=0
        )
        existing_ids = [str(t['id']) for t in existing['songs']]
        if existing_ids:
            apis.playlist.SetPlaylistTracks(
                op='del', pid=self.temp_pid, tracks=','.join(existing_ids)
            )

        # 2. 分批添加（单次最多1000首）
        for i in range(0, len(song_ids), 1000):
            batch = song_ids[i:i + 1000]
            apis.playlist.SetPlaylistTracks(
                op='add', pid=self.temp_pid, tracks=','.join(batch)
            )

        # 3. 调整顺序
        apis.playlist.SetPlaylistOrder(
            pid=self.temp_pid, ids=','.join(song_ids)
        )

        # 4. 唤起客户端播放
        OrpheusAddToNextInserter._send_orpheus({
            "cmd": "play", "type": "playlist", "id": self.temp_pid
        })
```

#### 2.4.3 历史记录存储：`HistoryStore`

```python
import json, os
from collections import deque

class HistoryStore:
    """本地 JSON 持久化的播放历史"""

    def __init__(self, file_path: str, max_size: int = 500):
        self.file_path = file_path
        self.max_size = max_size
        self._ids = deque(maxlen=max_size)
        self._load()

    def get_recent(self, window: int) -> list[str]:
        return list(self._ids)[-window:]

    def append(self, song_ids: list[str]):
        for sid in song_ids:
            self._ids.append(sid)
        self._save()

    def _load(self):
        if os.path.exists(self.file_path):
            with open(self.file_path, 'r', encoding='utf-8') as f:
                self._ids = deque(json.load(f), maxlen=self.max_size)

    def _save(self):
        with open(self.file_path, 'w', encoding='utf-8') as f:
            json.dump(list(self._ids), f, ensure_ascii=False)
```

## 三、核心数据流

### 3.1 完整执行流程

```
用户点击"执行"
      │
      ▼
[表现层] 收集输入 → 构造 ShuffleRequest
      │
      ▼
[应用层] ShuffleAppService.run(request)
      │
      ├─→ [基础设施] NcmApiClient.fetch(playlist_id)
      │       │
      │       ▼
      │   [领域] Playlist (含 list[Song])
      │
      ├─→ [基础设施] HistoryStore.get_recent(window)
      │       │
      │       ▼
      │   list[str] (近期播放ID)
      │
      ├─→ [领域] ShuffleStrategy.shuffle(songs, recent_ids)
      │       │
      │       ▼
      │   list[Song] (打乱后)
      │
      ├─→ [基础设施] QueueInserter.insert(song_ids)
      │       │
      │       ├─ OrpheusAddToNextInserter → orpheus:// addToNext
      │       └─ TempPlaylistInserter → API + orpheus:// play playlist
      │
      └─→ [基础设施] HistoryStore.append(song_ids)
              │
              ▼
          返回 ShuffleResult
      │
      ▼
[表现层] 展示结果
```

### 3.2 错误处理流程

| 阶段 | 可能错误 | 处理方式 |
|------|----------|----------|
| 抓取 | 网络失败、歌单不存在 | 捕获异常，提示用户检查网络/歌单ID |
| 随机 | 无（纯内存操作） | - |
| 插入 | 客户端未启动、协议失效 | 提示启动客户端；方案①失败可降级到方案② |
| 存储 | 文件读写失败 | 记录日志，不阻断主流程 |

## 六、技术选型决策

| 决策点 | 选型 | 理由 |
|--------|------|------|
| 主语言 | Python 3.10+ | 已有打包经验，pyncm 生态成熟 |
| GUI 框架 | Tkinter（首选）/ PyQt5（备选） | Tkinter 自带无需额外依赖；PyQt5 更美观但打包体积大 |
| 网易云 API | pyncm | 纯 Python，封装加密，支持分页 |
| 客户端通信 | orpheus:// 协议 | 官方协议，无需注入，最轻量 |
| 本地存储 | JSON 文件 | 轻量，无需数据库 |
| 随机算法 | 策略模式 | 便于扩展多种算法 |
| 队列插入 | 策略模式 | 便于在 orpheus/临时歌单/connector 间切换 |

## 七、可扩展性设计

### 7.1 新增随机算法
1. 在 `domain/shuffle/` 下新建文件，实现 `ShuffleStrategy` 接口
2. 在 `factory.py` 注册策略名
3. 无需修改其他层

### 7.2 新增插入方案
1. 在 `infrastructure/inserter/` 下新建文件，实现 `QueueInserter` 接口
2. 在配置中选择使用该 inserter
3. 无需修改领域层和应用层

### 7.3 新增数据源（如 QQ 音乐）
1. 在基础设施层实现新的 `PlaylistFetcher`
2. Song 模型可能需要扩展（如增加 source 字段）
3. 应用层不变

## 八、非功能性需求

| 维度 | 要求 | 实现方式 |
|------|------|----------|
| 性能 | 1000 首歌随机 < 100ms | Fisher-Yates O(n) |
| 可靠性 | 抓取失败可重试；插入失败可降级 | 应用层 try-catch + 策略降级 |
| 可测试性 | 领域层纯逻辑，可单测 | 领域层无外部依赖 |
| 可维护性 | 分层清晰，策略可插拔 | 分层架构 + 策略模式 |
| 轻量性 | 打包后 < 50MB | Tkinter + pyncm，无需 Electron |
